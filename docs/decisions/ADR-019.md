# ADR-019: Account-scoped token balance refresh

* **Date:** 2026-09-24
* **Status:** Accepted
* **Context & Problem:** Ethereum lacks an account balance-enumeration RPC. Refreshing every token ever discovered for a blockchain queried contracts unrelated to the selected account, which could display unsolicited or misleading balances.
* **Options Considered:**
  - Option A: Keep the blockchain-wide token set: discovers balances for all previously seen assets, but crosses account boundaries.
  - Option B: Refresh the native asset plus tokens present in this account’s balances or transfer history.
* **Decision:** Use Option B for manual and queued balance refreshes. Historical transfer tokens remain candidates even when their current balance is zero.
* **Consequences:** Accounts no longer query or display assets learned from another account. A token unknown to both the account’s balance rows and transaction history still requires discovery before it can be refreshed.
