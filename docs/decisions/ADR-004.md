# ADR-004: Local-Node UI Test Configuration

* **Date:** 2026-09-17
* **Status:** Accepted
* **Context & Problem:** Local-node UI tests need the app to connect to per-test EVM and Sui endpoints while exercising the production Ethereum testnet and Sui testnet account models. Transaction rows also need stable accessibility hooks for exact hash/digest assertions.
* **Decision:** Keep Sui networks limited to mainnet and testnet. When the debug app receives `--mnemonic`, create two Sui testnet and two Ethereum testnet accounts, applying `--sui-rpc-url` and `--evm-rpc-url` as their RPC overrides. UI tests start both local nodes in asynchronous setup and pass those endpoints through launch arguments.
* **Consequences:** Local-node tests use the same network identities and account naming as the app's normal testnet flows; no environment variables or synthetic localnet network are required.
