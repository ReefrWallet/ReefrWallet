# ADR-074: Hyperliquid DeFi plugin and completeness-aware totals

* **Date:** 2026-11-21
* **Status:** Accepted
* **Context & Problem:** HyperCore (Hyperliquid's L1) balances, perps, vaults, lending and stake aren't EVM balances, so wallets with HyperEVM accounts show none of them. Account modes change how balances add up, HIP-3 perp dexes may use non-USDC collateral, and some holdings have no price. Totals summed every DeFi `usdValue` as if exact, so a partial value could hide a loss.
* **Options Considered:**
  - Sum spot + perps + extras in every mode: wrong in unified and portfolio margin, where spot already holds perp equity (double counting).
  - `portfolio` endpoint's account value: one call and Hyperliquid's own number, but sampled every 15 min and on deposits.
  - Per-mode formulas reconciled against live accounts (chosen).
* **Decision:**
  - **Scope.** HyperEVM accounts only (mainnet → `api.hyperliquid.xyz`, testnet → `api.hyperliquid-testnet.xyz`), so one address isn't counted on every EVM chain. One record per account (`key = "account"`).
  - **Requests.** Every run: `userAbstraction` (never cached), `spotClearinghouseState`, `clearinghouseState` per perp dex (first 32; more leave both metrics partial), `borrowLendUserState`, `userVaultEquities`, `delegatorSummary`. `perpDexs`, `allPerpMetas` and `spotMetaAndAssetCtxs` are shared per network for 60 s.
  - **Prices.** Token → `markPx` of its USDC pair (contexts matched by `coin`); USDC = 1. HIP-3 equity and PnL × the dex's `collateralToken` price (dex from the universe's `dex:` prefix). Tokenless spot entries (outcome holdings) stay unpriced.
  - **Formulas** (2026-11-21, within 0.2% of `portfolio`'s account value on 13 live accounts; 0.01–0.03% where prices were read together):
    - `default`/`disabled`: spot + Σ perp `accountValue` + vaults + stake.
    - `unifiedAccount`: spot + lent + vaults + stake. Spot already holds cross and isolated perp equity.
    - `portfolioMargin`: spot + vaults + stake. Spot holds lent amounts and is net of debt.
    - Stake = `delegated + undelegated + totalPendingWithdrawal` × HYPE.
    - Unreconciled, so Portfolio Value is unavailable: `dexAbstraction` and unknown modes, standard mode with lending or with equity on a non-USDC-collateral dex (none of 500 leaderboard accounts had one), unified mode with borrowing.
  - **Unrealized PnL.** Σ positions' `unrealizedPnl` × collateral price, in every mode; partial while any position uses non-USDC collateral (unreconciled).
  - **States.** Each metric is `complete`, `lowerBound` (only nonnegative holdings unpriced), `partial` (a signed part unpriced: collateral, negative balance, skipped dexes) or `unavailable`.
  - **Record.** `usdValue` = Portfolio Value's priced sum in any state but unavailable, else 0; testnet → 0 (display only).
  - **Totals.** Plain `Decimal` sums of `usdValue`; no completeness flags or `≥`. Unpriced or not-yet-loaded parts count as 0. `DefiPositionModel.usdValue` defaults to 0, so ADR-073 stores with `nil` rows migrate.
  - **Rate limit.** Hyperliquid allows 1,200 weight/min per IP. `HyperliquidWeightAdapter` is a token bucket (capacity 100, 10/s) by request weight. It runs after WalletKit's gate and retrier on every attempt (`RateGateRegistry.makeProvider(adapters:eventMonitors:)`), so retries are charged and backlogs stay paced. It cancels its own waiters by request id. `validationType = .successCodes` sends 429/503 to the retrier.
  - **UI.** Hyperliquid section: Portfolio Value and Unrealized PnL (signed, colored when complete), with help marks for lower bound, partial and unavailable. Testnet is labelled, and its account shows no DeFi total. Key store details reload on saves.
* **Consequences:**
  - A mode switch takes effect on the next run.
  - Accounts in unreconciled modes or lending setups show PnL but no Portfolio Value until a fixture reconciles them.
  - On networks with more than 32 perp dexes (testnet has 288) both metrics are partial.
  - Fixtures in `TestVectors/Hyperliquid` record each formula with Hyperliquid's reference value.
