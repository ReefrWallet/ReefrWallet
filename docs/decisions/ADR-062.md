# ADR-062: Prune unused tokens on account deletion

* **Date:** 2026-11-09
* **Status:** Accepted
* **Context & Problem:** Account deletion left token metadata on disk after the last balance, approval, or staking position using it was removed.
* **Options Considered:**
  - Sweep every chain after deletion. This would touch unrelated accounts' chains and require a separate save.
  - Select unused tokens on the account's chain before the cascade and delete them in the same save.
* **Decision:** Use the chain-scoped cleanup. Add an optional inverse from tokens to staking positions. Keep tokens referenced by any remaining account and keep the chain's required native token. Save new tokens discovered by balance sync together with their balances.
* **Consequences:** Deleting an account also removes unreferenced token metadata and its source status records on that chain. A token seen only in transaction history can be rediscovered by sync.
