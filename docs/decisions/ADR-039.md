# ADR-039: Generate chain and token logos from @web3icons/core

* **Date:** 2026-10-21
* **Status:** Accepted
* **Context & Problem:** Hand-collected `Logos.xcassets` was inconsistent in style and size and had no template variants for the sidebar.
* **Options Considered:**
  - Keep hand-collected SVGs: no extra tooling, but manual and inconsistent.
  - Generate from `@web3icons/core` (MIT): one consistent set with mono and background variants.
* **Decision:** `Scripts/make_web3icons.sh` lists networks and tokens and runs `Scripts/web3icons/build.mjs` against `@web3icons/core` pinned in its `package.json`.
  - `Networks.xcassets`: mono network icons, 16pt magenta template, `<name>Network16`. Used in the sidebar.
  - `Tokens.xcassets`: background token icons clipped to a circle, 16pt color, `<symbol>Token16`. Used as chain logos elsewhere. Tokens without an icon (BASE, HOOD, HYPE, MON) use their network's background icon.
* **Consequences:** Adding a chain/token is a list edit plus a script run. Generated catalogs are checked in; Node is needed only to regenerate.
