# ADR-014: Cardano native-asset transfer construction

* **Date:** 2026-09-21
* **Status:** Accepted
* **Context & Problem:** Cardano accounts already discover native assets, but transfer construction discarded every asset-bearing UTxO and rejected a selected native asset.
* **Decision:** Build Cardano values from full Blockfrost UTxOs, parse asset units as policy ID plus asset name, and preserve unselected assets in change. A native-asset recipient output carries an explicit user-entered lovelace amount and is rejected by the ledger builder when it does not meet minimum-ADA rules. Trezor signs the same expanded envelope through Cardano's structured protocol; the host accepts witnesses only after the device's reconstructed transaction-body hash matches the canonical body.
* **Consequences:** ADA and one selected native asset can share the standard transfer flow for local and Trezor accounts. Staking, scripts, and multi-recipient/bundle composition remain out of scope.
