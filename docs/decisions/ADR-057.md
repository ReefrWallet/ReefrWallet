# ADR-057: Per-source token status and token identity

* **Date:** 2026-11-07
* **Status:** Accepted
* **Context & Problem:** A token no source can price cost RPC and HTTP calls on every failed pass, forever (ADR-047, ADR-055), and nothing recorded which source failed or why. Any token with a price also counted as real: spam got priced and summed into totals, and on Ethereum a token reusing a symbol borrowed the real feed's price, since feeds were found by symbol through ENS.
* **Options Considered:**
  - Negative cache in memory: lost on relaunch, no history.
  - Flags on `TokenModel` per source: a column per provider.
  - One status row per token, source and pipeline (chosen): new providers need no schema change.
  - Treat an absent price as "not listed": the price endpoint doesn't document that, so a listed but unpriced token could be hidden for a week.
* **Decision:**
  - `TokenSourceStatusModel` (`kind`: price, identity or metadata; source id; `lastSuccessAt`, `lastError`, `lastErrorAt`, `unavailableAt`, `externalId`), cascade-deleted with its token. Lightweight migration.
  - A source is skipped for a token for 7 days after `unavailableAt`. Unavailable means `TokenNotListed` (no liquid Uniswap pool, absent from a fresh listing), a reverting call, or an empty result. Transport and HTTP errors, rate limits and stale Chainlink answers are logged and retried normally. `NoQuote` (CoinGecko answered without a price) is recorded and retried normally. A `nil` answer means the source declined without asking and writes nothing, so new table entries and keys apply at once.
  - The price service owns recording and skipping, so staking and fee callers benefit too. A token reports its most telling error: rate limit, then transient, then miss, so a later miss can't hide a 429.
  - Identity is a pipeline parallel to pricing (`Sources/Services/Token Identity/`). `TokenIdentitySource` is batched; sources run in order and the first to identify a token wins. `ChainlinkFeedIdentitySource` identifies tokens in the hand-checked feed tables with no network. `ListingIdentitySource` wraps any `TokenListingProvider`; `CachedTokenListing` keeps the provider's full listing for 24 h in memory and in Caches, and backs off on its own. CoinGecko's `/coins/list?include_platform=true` works without a key (about 4 MB, 22,800 coins in November 2026). A miss in a stale listing is transient, never a skip. Image lookups (`TokenMetadataSource`) are best effort with their own queue and backoff.
  - `TokenModel.isWhitelisted` is set only by identification, never reset. Unidentified non-native tokens are hidden, not priced and excluded from totals. A configuration version (source ids and table hashes) in `UserDefaults` makes rejected tokens due again when a source or table changes.
  - Identification makes the token's price due at once (`priceUpdatedAt` and the failure flag reset, price skips cleared) and nudges the price scheduler.
  - Ethereum Chainlink feeds are an address table (`ChainlinkFeeds.ethereum`), and ENS lookup left pricing, closing the symbol spoofing gap noted in ADR-055. Heartbeats use the 24 h ceiling.
  - Price, CoinGecko id, image and whitelisting of an existing row are written only by their own writers; `upsertTokenModel` updates descriptive fields, so an older balance snapshot can't overwrite a newer quote.
  - The balance screen's refresh key (`BalanceModel.refreshKey`) includes price, whitelisting and image, so they update an open screen with an unchanged amount.
  - CoinMarketCap or CoinAPI plug in as a `TokenListingProvider`, `TokenMetadataSource` and/or `PriceSource`, matched on contract address only. A token passes if any list has it.
* **Consequences:**
  - Failing tokens cost one attempt per source per week. After updating, tokens outside the feed tables are excluded from totals until identified and priced, longer if offline or if the keyless list fails. Mac lists them under Hidden Tokens; iPhone shows them in the main list unless Hide Unknown Tokens is on.
  - A newly listed token can wait up to 7 days after a negative answer, unless a source or table changes. The filter is as strict as the loosest list.
  - Ethereum feeds need upkeep: tokens outside the table fall through to Uniswap and CoinGecko. Heartbeats are loose until each feed is checked.
  - Non-EVM address forms (Cardano, Tron, Aptos, Sui) are matched exactly or in canonical form and were not checked against live app data; a mismatch hides the token rather than showing spam.
