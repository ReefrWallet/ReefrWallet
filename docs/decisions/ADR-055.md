# ADR-055: Per-chain price routes

* **Date:** 2026-11-07
* **Status:** Accepted
* **Context & Problem:** Every token was offered to every price source, each declining or failing on its own (ADR-027). That cost RPC calls and log noise, and Chainlink (ENS feeds, L1 only) and Uniswap (Ethereum's factory and USDC) worked only on Ethereum. Chainlink also accepted any positive answer, so a stopped feed never fell back.
* **Options Considered:**
  - Keep self-declining sources and add chain checks inside each: spreads routing across sources and still tries them all.
  - Per-chain route table in front of the sources, then universal sources (chosen).
  - Resolve Chainlink feeds on-chain for every chain: no registry exists outside Ethereum's ENS.
* **Decision:**
  - `PriceRoutes` maps a mainnet `Blockchain` to its sources; `universal` (CoinGecko) follows every route. `TokenPriceService` tries the token's route then universal, last successful source first (ADR-047) if it is in that list. Source ids are unchanged, so no migration. A custom EVM chain with a known id (`EVMBlockchain(chainId:)`) uses that chain's route; testnets and unknown ids only reach universal sources.
  - Routes: Ethereum, Arbitrum, Avalanche, Base, BSC, Monad, Optimism, Polygon, Robinhood, Unichain: Chainlink then Uniswap V3. HyperEVM, Mantle: Chainlink only (HyperEVM's V3 factory had no pool against the quote tokens tried; Mantle has no V3). Sui: Cetus.
  - Ethereum keeps ENS feed lookup. Other chains use fixed feed tables in `ChainlinkFeeds.swift`, keyed by lowercased contract address, never symbol, so a spam token can't borrow a feed. The native token uses its wrapped token's feed. Tokens outside a table fall through with no RPC call.
  - Chainlink answers must be fresh: `updatedAt` within the feed's heartbeat plus 15 min (ENS feeds: 24 h plus 15 min), at most 5 min ahead of the device clock. Otherwise `StaleAnswer` is thrown and the next source is tried.
  - Uniswap takes a per-chain `Deployment` (factory, USD quote token, treated as $1). Robinhood quotes against USDG.
  - CoinGecko's Robinhood platform id was wrong (`robinhood-chain`); it is `robinhood`.
* **Consequences:** Tokens no longer hit sources that can't price them, and every routed chain gets on-chain prices. Adding a chain's route is a table entry. Feed tables and heartbeats are static and need upkeep; a raised heartbeat only causes fallback to the next source. Tokens outside a table pay up to four Uniswap `getPool` calls per failed pass on routed chains, bounded by ADR-047's 10 min retry. Ethereum still resolves Chainlink feeds by symbol; moving it to an address table would close that spoofing gap.
