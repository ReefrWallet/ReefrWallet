# ADR-009: Dedicated WalletKit Test Infrastructure Target

* **Date:** 2026-09-20
* **Status:** Accepted
* **Context & Problem:** Local Anvil and Sui node helpers were compiled into the production `WalletKit` module, exposing test-process and local-node dependencies to non-test consumers.
* **Options Considered:**
  - Option A: Keep the helpers in `WalletKit`: no target changes, but production code retains test-only infrastructure.
  - Option B: Create a macOS-only `WalletKitTesting` framework that depends on and re-exports `WalletKit`: keeps production and test infrastructure separate while preserving concise test imports.
* **Decision:** Use Option B. `EthereumNode` and `SuiNode` live in `WalletKitTesting`; macOS unit and UI tests import that module rather than `WalletKit` directly.
* **Consequences:** Production `WalletKit` no longer compiles local-node lifecycle code. Test targets retain access to WalletKit APIs through `WalletKitTesting`; the local-node helpers remain macOS-only.
