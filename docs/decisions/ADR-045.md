# ADR-045: Verify hardware key identity before signing

* **Date:** 2026-10-23
* **Status:** Accepted
* **Context & Problem:** Scans report a placeholder id (`trezor-usb-0-Safe5-false`), not the device's real id, which is known only after connecting. Key stores saved the placeholder, so a different Trezor of the same model passed the match and signed with the wrong keys.
* **Options Considered:**
  - Keep matching scan ids: can't tell two same-model devices apart.
  - Connect the first device found and compare its real id (`Features.device_id`) with the stored one: needs a connection per sign, which already happens.
* **Decision:** `HardwareService.connect(_:deviceId:)` connects the vendor's devices in turn, disconnecting each whose real `device.info.id` differs from the key store's `deviceId`, and throws `HardwareServiceError.wrongDevice` if none matches, shown by the existing error alerts. Adding a Trezor connects the first device without a key store yet (`alreadyExists` if all have one) and saves the real id, vendor (`trezor`) and a new `KeyStoreModel.model` (`Trezor Safe 5`).
* **Consequences:** Key stores added before this change hold a placeholder id and report "wrong device" until re-added. The scan model is always `Trezor`, so same-session devices are told apart only by connecting.
