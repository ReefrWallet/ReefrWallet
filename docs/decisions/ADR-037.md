# ADR-037: Penpot design file mirrors the SwiftUI design system

* **Date:** 2026-10-18
* **Status:** Accepted
* **Context & Problem:** The design system lives only in code (`Style.swift` sizes, `Positive`/`Negative`/`Caution` color assets, system colors) and there is no design file. Designs need a reference that matches the app.
* **Options Considered:**
  - Penpot via MCP plugin: matches AGENTS.md tooling; tokens, library colors/typographies, variant components. Cons: no SF Pro or SF Symbols, no native macOS controls.
  - Figma: richer tooling, but not the project's chosen design tool.
* **Decision:** Recreated the system in Penpot with Foundations, Components and per-platform screens pages (`Screens / Mac` holds the existing designs; `Screens / iPhone` has Accounts (sidebar root) and Account Transactions so far, `Screens / iPad` is empty):
  - **Foundations:** library colors (light/dark pairs), typography styles named after `StyledView.Size`, token sets `color/light`, `color/dark`, `core` (spacing, radius) with `Appearance` Light/Dark themes, plus swatch and type-scale boards.
  - **Components:** variant components for Transaction Badge, Status Pill, Word Token, Button; components for Sidebar Add Button, Sidebar Account Row, Key Store Header, Empty State.
  - **Account Header** is a variant component with `Platform` (Mac, iPhone); screens use instances.
  - **Mac parts** Sidebar Section Header (`Add` No/Yes), Segmented Control (`Selected`) and Window Controls are components used by all Mac main screens. Sheets, forms (Text Field, Form Row, Buttons) and tables (Table Row/Header, Balances/Accounts Table) are still built from plain boards.
  - **Mac Tab Bar** (`Selected`) and **Mac Transaction Table Header** (`Chain`) are components; the Mac transactions screen is a table of those plus `Transaction Row` Mac variants, sized for the 860pt detail pane.
  - iPhone has no key store details screen, so the indented iPhone Account List Row shows the account's USD value.
  - **iPhone parts** (Status Bar, Home Indicator, Navigation Bar, Tab Bar, Section Header, Account/Key Store List Row, List Count Header); transaction lists use Transaction Row instances with plain separators are components; `Screens / iPhone` contains only instances of them.
  - **Transaction Row** is a variant component with `Platform` (iPhone list row, iPad fixed-column table row, Mac chain-specific table row) × `Chain` (EVM, Tron, Aptos, Solana, Sui, Bitcoin, Cardano). Mac columns follow `TransactionTableSchema` (From/Dir/To vary per chain); sample data is per chain.
  - Template icons use the magenta fill `#FF00FF`.
  - **Screens / Mac:** main window (balances, transactions, key store, no selection) and the Send, Add Account, Add Key Store, Connect App, Add dApp, Backup, WalletConnect proposal, dApp request sheets and Settings.
  Approximations: Inter replaces SF Pro, Roboto Mono replaces SF Mono, glyphs replace SF Symbols, chain/token logos are colored circles, and macOS system label/background colors are hardcoded light/dark values.
* **Consequences:** Penpot is a visual reference; the code remains the source of truth. Color tokens exist but are not bound to most shapes. Changes to `Style.swift` or the color assets must be mirrored by hand.
