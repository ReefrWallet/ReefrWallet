# ADR-046: Disconnect dApps When Accounts Are Deleted

* **Date:** 2026-10-23
* **Status:** Accepted
* **Context & Problem:** Deleting an account or key store left browser grants and live WalletConnect sessions pointing at addresses the wallet no longer holds.
* **Options Considered:**
  - Filter stale accounts at request time: leaves sessions and grants listed as connected.
  - Revoke on deletion: sessions and grants disappear immediately.
* **Decision:** `AccountService.disconnectDapps(from:)` runs after deletion (also via `KeyStoreService.deleteKeyStore`). It revokes browser grants and disconnects WalletConnect sessions for deleted addresses, skipping addresses another account still uses.
* **Consequences:** A WalletConnect session is dropped whole if any approved account is deleted. Already-open browser tabs keep in-memory permissions until reload.
