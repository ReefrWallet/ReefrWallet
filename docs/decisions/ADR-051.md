# ADR-051: Mail-style navigation, account filters and zoom sheets

* **Date:** 2026-11-03
* **Status:** Accepted
* **Context & Problem:** ADR-050 defines a Mail-like design in Penpot. The app still grouped key stores by kind, used a `TabView` with a table-heavy account view, and presented every sheet with the default slide-up.
* **Options Considered:**
  - Restyle only the iPhone: small change, but Mac and iPad drift from the design.
  - Follow the design on all platforms, with native fallbacks where a platform lacks the Mail behavior.
* **Decision:** Follow the design on all platforms.
  - **Sidebar:** one collapsible section per key store (hardware, local, watch-only), accounts as rows with USD value; a collapsed section shows the store total. The state is persisted as `KeyStoreModel.isCollapsed` (lightweight migration, set through `DatabaseService`). Mac: the add button and chevron show on header hover, context menus replace edit mode. iPhone: Edit enters Contacts-style edit mode (red remove, green "Add Account…", "New Key Store" in the bottom bar). The mode is app state, not SwiftUI `EditMode`, because `List(selection:)` would add selection circles.
  - **Account details (iPhone):** large title/subtitle instead of the address header; `AccountTabChips` replace `TabView` (Balances, Transactions, Approvals where supported; Staking/NFTs wait for the features). iPhone only: macOS keeps the `TabView` with `TransactionsTable`, `AccountBalancesTable` and the approvals table. Hidden balances disclosure is replaced by the filter on iPhone.
  - **Filters:** `AccountFilter` (Addressed: To account / To My Accounts / From My Accounts; Include Unknown Tokens; Hide Zero Balances), stored as JSON in `@AppStorage`. iPhone shows a sheet and a "Filtered by" pill; Mac has no filter. Unknown tokens are `TokenModel.isHidden`.
  - **Zoom sheets:** `sheetSource(_:)` marks the button, `sheetZoom(from:namespace:)` applies `.navigationTransition(.zoom)` to the sheet; `PresentedSheet.id` doubles as the source id. iOS/iPadOS only, since macOS has no zoom sheet transition and keeps native sheets.
* **Consequences:** Transaction hash, block and fee columns are not visible on iPhone until a detail screen exists. Zoom sheets from toolbar menus fall back to the default presentation when the source id doesn't match (e.g. watch-only Add Account). The filter is global to all accounts. Supersedes the table layouts of ADR-034 and the sidebar structure of ADR-040.
