# ADR-033: CoinGecko mainnet token-price fallback

* **Date:** 2026-10-16
* **Status:** Accepted
* **Context & Problem:** Chainlink, Uniswap V3, and Cetus price only a subset of assets. The wallet supports additional mainnet chains and tokens that need an app-owned market-data fallback.
* **Options Considered:**
  - Option A: Add price providers to WalletKit: couples chain primitives to market-data policy.
  - Option B: Add CoinGecko after existing app-owned sources: preserves ADR-027's boundary and on-chain source precedence.
* **Decision:** `CoinGeckoPriceSource` is the final `TokenPriceService` source. It uses the CoinGecko Demo API with a user-configured key, native coin IDs for native mainnet assets, and asset-platform contract lookups for supported non-native assets. Its Moya client uses the shared rate gate at CoinGecko Demo's 30 calls/minute limit. Testnets and custom EVM networks do not make CoinGecko requests. Native CoinGecko IDs are persisted on tokens after a successful quote.
* **Consequences:** Every supported mainnet family can obtain an aggregated USD quote when CoinGecko lists the asset. Pricing depends on the user's Demo API allowance; unlisted assets remain unpriced and on-chain quotes remain preferred.
