# ADR-036: Asset-count amount for multi-asset transactions

* **Date:** 2026-10-17
* **Status:** Accepted
* **Context & Problem:** Figma shows transactions changing several assets as a count ("2 Tokens", "2 NFTs, 4 Tokens") instead of one amount. WalletKit has no NFT effect kind.
* **Options Considered:**
  - Option A: Add an NFT effect kind to WalletKit: clean, but touches every history client.
  - Option B: Classify in the app's presenter from data already stored: no WalletKit change, EVM only.
* **Decision:** Option B. `TransactionRowEffect.assetClass` is `.nft(tokenId:)` for EVM `.tokenTransfer` effects whose raw log has 4 topics (ERC-721 indexes the token ID), else `.token`. Each NFT is a distinct asset (`assetKey` = contract + token ID), so `.multiAsset` is decided by distinct `assetKey`s. `.multiAsset` rows show the count (NFTs first, `.primary`); plurals live in `Resources/Localizable.xcstrings`.
* **Consequences:** ERC-1155 and non-EVM NFTs count as tokens until WalletKit exposes them. The accessibility amount marker still carries the primary effect's raw amount.
