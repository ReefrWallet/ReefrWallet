# ADR-038: Open WalletConnect dApps in a preferred browser

* **Date:** 2026-10-21
* **Status:** Accepted
* **Context & Problem:** WalletConnect sessions (ADR-035) list a dApp's URL but give no way to open it. Users may want dApps in a browser other than the system default.
* **Options Considered:**
  - Open in the in-app browser: but WC dApps already talk to the wallet over the relay; mixing in the injected provider would create a second session.
  - Open externally in a browser picked in Settings, falling back to the system default.
* **Decision:** Each session row has an "Open in Browser" button calling `PreferredBrowser.open`. Only http(s) URLs are opened (dApp metadata is untrusted).
  - macOS: Settings › dApps picks from installed apps that open https URLs; stored as `PreferredBrowserBundleId` in `UserDefaults`. Empty or uninstalled → system default.
  - iOS: no Settings scene and no public API to target a browser, so the system default browser is used.
* **Consequences:** Browser choice is per-device and macOS-only. Browser dApps in the sidebar still open in the in-app browser.
