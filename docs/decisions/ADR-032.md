# ADR-032: Bundled @mysten/sui for dapp transaction building

* **Date:** 2026-10-15
* **Status:** Accepted (supersedes ADR-023's hand-written `providers/sui-transaction-builder.js`; its native lookups and decoder stand)
* **Context & Problem:** `sui-transaction-builder.js` (~1000 lines) re-implemented `@mysten/sui`'s resolver and BCS encoder, and had to track Mysten's JSON format and resolution algorithm by hand.
* **Options Considered:**
  - Keep the hand-written builder: small (36 KB), but ours to maintain.
  - Bundle `@mysten/sui`'s `Transaction`: ~107 KB minified, upstream resolution/encoding. No browser dist exists (unlike TronWeb), so it's built from npm with esbuild.
* **Decision:**
  - `Scripts/sui-sdk/` (pinned `package.json`/lockfile, `entry.mjs`, `build.mjs`) generates `vendor/sui-sdk.js`: `Transaction` plus the SDK's `coreClientResolveTransactionPlugin` (deep import; not in its exports map), in a wrapper evaluated on first `window.__reefrLoadSuiSDK()`, like `tronweb.js`. Regenerate with `npm ci && npm run build` there.
  - `providers/sui.js` builds with `Transaction.from(json).build({client})`; `makeCoreClient` maps the `client.core` calls the resolver makes onto the existing native `sui` lookups (base64 digests → base58, owner/type shapes).
  - Native gas stays coin-object only: `getBalance` reports no address balance and `expiration` is pinned to `None`, so the SDK never emits coin reservations or `ValidDuring` (which `SuiTransactionDataDecoder` rejects). `getChainIdentifier`/epoch are stubbed: only those paths use them.
  - sui.js still rejects foreign senders, sponsored gas and non-`None` expirations early; Publish/Upgrade are left to the native decoder.
* **Consequences:** ~1000 fewer hand-written lines; `TestVectors/sui-dapp-transactions.json` still matches byte for byte. Gas payment now uses all the sender's SUI coins (SDK behavior) instead of the fewest covering the budget. SDK upgrades: bump the version, rebuild, rerun `SuiTransactionBuilderScriptTests` — a resolver that calls new `client.core` methods fails there first. Address-balance gas needs native decoder support before the `getBalance` stub can go.
