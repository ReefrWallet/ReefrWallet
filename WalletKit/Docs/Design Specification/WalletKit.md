DESIGN SPEC — not generated code.

This module describes the target public Swift API surface for
WalletKit, the shared key-management core backing Reefr Wallet. The real
bindings for these types will be generated by UniFFI from the Rust
`walletkit-keys` / `walletkit-hardware` / `walletkit-ffi` crates; the
signatures throughout this module are the contract that Rust
implementation is expected to satisfy. Object types map to UniFFI
`interface` declarations (→ Swift classes); simple types map to UniFFI
`record`/`enum` declarations (→ Swift structs/enums).

Scope: mnemonic-based key management plus hardware wallets as a
first-class key signer. Trezor is the first hardware vendor
targeted; the abstraction is written so other vendors (Ledger,
Keystone, ...) can be added as their own modules later without
changing this surface. Blockchain-specific clients (address
derivation, transaction signing per chain) are still a later phase;
see ChainClients/ for the intended extension points.

Every type lives in
its own file under a subfolder here:

  Errors/         WalletKitError
  Core/           Curve, DerivationScheme, Wordlist, MnemonicWordCount,
                  CoinType, Blockchain, DerivationPath
  Keys/           Mnemonic, Seed, ExtendedKey, PublicKey, PrivateKey
  Accounts/       KeySource, Account, KeyProvider
  Wallet/         Wallet, WalletBackup
  Hardware/       HardwareVendor, HardwareTransportKind,
                  HardwareDeviceInfo, HardwareInputRequest,
                  HardwareButtonRequest, HardwareDeviceDelegate,
                  HardwareDeviceManager, HardwareDevice
  ChainClients/   ChainClient, HardwareChainSigner
